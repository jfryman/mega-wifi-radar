# Terminology

- MegaWiFi - doragasu's Wi-Fi cart design and API; an ESP module bridged to the 68k over a UART.
- Rev.C - the owner's board revision (jfryman/mw-cart): 20 MHz UART clock, 1.25 Mbaud, 8 MiB flat flash.
- 16C550 - TI TL16C550D UART at `$A130C1` (odd bytes, register n at `+2n`).
- LSD - the framing protocol over the UART (STX/ETX, channel nibble, 12-bit length); 4 channels.
- Channel 0 - LSD control channel used by `mw_*` commands.
- MW_HTTP_CH - LSD channel 3 (`LSD_MAX_CH - 1`) that carries HTTP bodies.
- Socket channels - LSD channels 1–2, usable by `mw_tcp_connect` / `mw_udp_set`.
- MSS frame - one LSD payload of at most 1460 bytes.
- mw-fw-rtos - the ESP32 firmware; the owner's fork has the `rev-c-1250k` release.
- wflash - the MegaWiFi bootloader; the stock build doesn't fit Rev.C clocks.
- User task - SGDK's cooperative task (`TSK_userSet`) that runs `mw_process()`; it must never touch the VDP.
- Compact frame - the big-endian binary aircraft snapshot the console consumes (`"AR"`, `src/arframe.h`).
- Record - one 24-byte aircraft entry in a frame (v2 adds the type → 28).
- 1/32 nm - frame position unit (~58 m); x east, y north of home.
- Stale - position older than 15 s (flagged); older than 60 s means dropped by the relay.
- Digester - whatever turns ADS-B JSON into compact frames (relay = option A, firmware = option B).
- Fake source - canned compact frames in ROM, used in emulators.
- Blip - an aircraft's current-position marker on the scope.
- Trail - the last N positions of an aircraft, drawn behind the blip.
- Data tag - the text block next to a blip (callsign / altitude / ground speed).
- Sweep - the rotating radar line: a thin line drawn into plane B pixels, 256 steps/rev, with a palette-faded afterglow.
- Glow slot - one of the 10 PAL0 indices a sweep pixel is written with; rotating the palette fades the tail.
- Theme - palettes + flags (Classic: green phosphor + sweep; STARS: modern, no sweep).
- nm - nautical mile; frames use 1/32 nm.
- Home point - the scope centre (airport ICAO + lat/lon in 1e-4 deg + range nm). Dev default KBNA.
- KBNA - Nashville International, the dev home point (36.1245, -86.6782, 599 ft).
- Config screen - the setup screen (`setup.c`): theme, range, tags, airport, Wi-Fi, relay; opens on START or when boot can't connect.
- Squawk 7500/7600/7700 - hijack / radio failure / emergency transponder codes.
- H40 - the 320×224 VDP display mode.
- Trim - the finished size of a printed piece after cutting (`print/dims.toml`).
- Bleed - the 3 mm of art beyond the trim on every edge, so a slightly-off cut shows no white.
- Slug - the 9 mm margin outside the bleed that carries the crop marks (dropped with `marks=false`).
- Imposition - arranging manual pages onto sheets so that, printed duplex and folded, they read in order (`booklet.typ`).
- Key art - the hero illustration shared by label, cover and manual: the vector scope from `keyart.typ`.
- Black grid - the fine grey-on-black grid of 1989 US Genesis boxes, our cover background (`grid-tiling`).
- AUTO - RELAY setting left empty: the cart finds the relay over mDNS at every boot (`_mwradar._tcp`).
- Legacy unicast query - an mDNS query sent from a port other than 5353; responders must answer it directly to that port (RFC 6762 §6.7).
- Reuse mode - a MegaWiFi UDP socket opened with only a local port: packets carry a 6-byte peer address prefix.
- Contract version - `AR_VER` in `src/arframe.h` (= relay `frameVer`); sent as `v=` on every request and in the mDNS TXT. Any contract change bumps it.
- Lock-step - relay vX serves only cart vX (same release, same `AR_VER`); a mismatch is a 409 and an on-screen `RELAY MISMATCH` / `RELAY VER?`.
- Contract lock - `relay/contract.lock`: `AR_VER` + a hash of `arframe.h`, so the header can't change without a bump (`make contract-lock`).
- Traffic list - the side panel's sortable callsign + distance list; ▲▼ select in it (`tlist.c`).
- Sort order - the list's order, cycled by holding C: NEAREST, A-Z, Z-A, LOW ALT, HIGH ALT (emergencies always first).
- Detail pop-up - the full-height panel over the scope (tap C) with everything about the selected aircraft (`popup.c`).
- Detail record - `struct ar_detail`, 96 bytes from `GET /v1/detail`: registration, type, model, operator, year, GPS/selected altitude, selected heading, QNH, last seen.
- Opaque font - a copy of the SGDK font with its transparent background made black (index 14), so window-plane text hides the scope.
- Desync - SGDK pairs each command with the next channel-0 reply; after a timeout the firmware's late replies shift every later pairing, for good.
- Cockpit mode - the view from one aircraft over real terrain, drawn by the cart (A in the pop-up, or Y); `cockpit.c`.
- Voxel Space - the Comanche (1992) terrain technique: per screen column, march out in depth over a heightmap + colour map, drawing each column front to back; `voxel.c` + `vox.s`.
- Terrain patch - 128×128 cells of height levels and palette indices from `GET /v1/terrain`, centred on the aircraft, cell size = height above ground / 5.
- Patch key - `"lat,lon,cell,level,base,hi"` in a patch's header; the cart sends it back as `p=` on `/v1/track` and `/v1/strip`, so the relay stays stateless.
- Strip - 8 × 128 cells of a patch's grid (`/v1/strip`), streamed into cockpit mode's wrapping buffer ahead of the aircraft.
- Height level - a patch's vertical unit (`level_cm`, normally cell / 16: true scale); 0..63 above `base_m`.
- Mode overlay - `overlay_ram`: 36 KB that the radar (scope tiles, trails, tracks) or cockpit mode (`struct vox_ram`) owns at a time.
- Sky delta - repaint only the sky rows a VRAM copy's terrain uncovered since that copy's last frame.
- Reconnect - module reset (`mw_init`) + detect + join + relay lookup after 3 failed requests in a row, backing off 15/30/60 s (`feed_reconnect`).
- 32X - Sega's Genesis add-on (two SH-2s, 256 KB SDRAM, a 256-colour frame buffer); plan in `plans/32x.md`.
- MARS ID - `"MARS"` read at `$A130EC` when a 32X is attached.
- ADEN - 32X adapter-enable bit; once set, the cart ROM moves to `$880000` (fixed 512 KB) and `$900000` (1 MB bank).
- RV bit - 32X bit (`$A15107`) that restores the Genesis ROM mapping for VDP DMA; the SH-2s can't read ROM while it's set, and the 68000 needs it set to read or write the MegaWiFi UART in 32X mode.
- FM bit - bit 15 of the 32X adapter control register: set, the SH-2s own the 32X VDP (frame buffer, palette).
- MARS header - the 32X block at ROM `$3C0`: where the boot ROMs copy SH-2 `.data` from, and the two SH-2 entry points.
- Sega boot code - the 1040-byte 68000 security/boot code every 32X cart has at `$3F0`; fetched from pinned marsdev, never in the repo.
- COMM registers - sixteen bytes at `$A15120` (68k) / `$20004020` (SH-2) both sides read and write; the spike gives each one writer.
- mwradar-mars - the 32X build image (`mars/Dockerfile`, `scripts/mars`), separate from `mwradar-sgdk`.
